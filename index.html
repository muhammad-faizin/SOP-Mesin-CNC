01 Pendahuluan

Standar Operasional Prosedur (SOP) ini dirancang sebagai panduan wajib bagi seluruh mahasiswa, laboran, dan dosen di lingkungan Laboratorium Teknik Mesin Universitas Jenderal Soedirman dalam mengoperasikan Mesin CNC (Computer Numerical Control).

Tujuan SOP ini adalah untuk:

  • Mencegah terjadinya kecelakaan kerja selama praktikum atau pengerjaan proyek.
  • Menjaga umur pakai (lifetime) komponen mesin CNC akibat kelalaian operasional.
  • Memastikan hasil pengerjaan presisi dan sesuai spesifikasi.

02 Spesifikasi Mesin CNC

Berikut adalah spesifikasi teknis untuk mesin Jaglo VF-500i (Standar Industri Bawaan) yang ada pada Laboratorium Teknik Mesin:

Travel Sumbu X/Y/Z 500 / 380 / 400 mm
Tipe Spindle & Taper Direct Drive, BT30
Max Speed Spindle 12.000 RPM
Ukuran Meja (Table) 650 x 380 mm
Kapasitas Tool/ATC 20 Tools (Arm Type)
Sistem Kontrol CNC Mitsubishi M80

03 Keselamatan Kerja (K3)

Alat Pelindung Diri (APD)

Alat keselamatan yang WAJIB digunakan:

  • Kacamata Safety (Safety Goggles)
  • Sepatu Safety (Safety Shoes)
  • Pakaian kerja/wearpack laboratorium

Larangan Keras!

  • Dilarang keras memakai sarung tangan kain saat mesin sedang running/spindle berputar.
  • Lepaskan seluruh perhiasan, jam tangan, dan cincin.
  • Bagi yang berambut panjang, rambut wajib diikat erat ke belakang.

05 Langkah Prosedur Operasi

1. Power ON

Putar saklar utama (Main Switch) yang terletak di bagian belakang/samping mesin ke posisi 'ON'. Kemudian, tekan tombol POWER ON pada panel kontrol CNC dan tunggu hingga sistem OS/Controller booting sepenuhnya.

2. Return to Reference Point (Zero Return)

Bebaskan tombol Emergency Stop (Putar ke kanan). Lakukan Zero Return / Reference Return untuk sumbu X, Y, dan Z (untuk Milling) atau X dan Z (untuk Lathe/Bubut). Ini wajib dilakukan agar mesin mengetahui posisi referensi awalnya.

3. Setting Titik Nol Benda Kerja

Gunakan Edge Finder atau Tool Sentuh untuk menentukan titik nol (X0, Y0, Z0) dari benda kerja. Masukkan nilai koordinat offset tersebut ke layar WORK OFFSET (G54 / G55 dsb).

4. Input Program & Dry Run

Transfer program G-Code dari USB/Jaringan ke memori mesin. Sebelum pemotongan aktual, gunakan mode DRY RUN dan perlambat Feedrate Override serta amati pergerakan tool (pastikan posisi tool sedikit dijauhkan / Z+ agar tidak menabrak benda).

5. Eksekusi Program (Auto Mode)

Ubah mode ke AUTO / MEM. Aktifkan Coolant, tutup pintu pelindung mesin rapat-rapat. Putar Rapid Override ke persentase rendah (25%), tekan tombol CYCLE START secata hati-hati, amati tool menyentuh material.

06 Estimasi Cycle Time

Kalkulator mandiri untuk menghitung perkiraan waktu pemesinan

Pada layar controller Mitsubishi M80, Cycle Time aktual akan otomatis direkam dan dapat dilihat di pojok kanan bawah Monitor (Layar Monitor Utama). Jika Anda perlu merencanakan estimasi dasar sebelum mengeksekusi program, gunakan kalkulator pemotongan lurus sederhana berikut:

Waktu Pemotongan Murni: 0 Menit 0 Detik

*Waktu ini adalah teori pemotongan linier (G01). Belum termasuk waktu G00 (Rapid Traverse) dan Tool Change.

07 Prosedur Pasca-Operasi

  • Membersihkan Mesin

    Gunakan semprotan udara (air-gun) untuk menyingkirkan beram, lalu sapu beram keluar dari bak penampung. Bilas dengan air coolant untuk menghilangkan residu sisa. Mesin harus ditinggalkan dalam keadaan bersih seperti sedia kala.

  • Melepaskan Benda Kerja & Tool

    Lepas alat potong dan kembalikan ke rak tool. Lepas benda kerja dari chuck/ragum.

  • Posisi Parkir Mesin

    Pindahkan axis X dan Y di tengah meja, dan turunkan sumbu Z secukupnya dalam posisi parkir aman. Jangan biarkan tool holder tersangkut di atas ragum.

  • Power OFF

    Tekan EMERGENCY STOP. Matikan panel POWER OFF, tunggu hingga layar LCD mati. Terakhir, putar saklar utama (Main Switch) ke posisi 'OFF'.

Prosedur Keadaan Darurat

Apabila terdengar suara benturan/tabrakan (Crash), getaran tidak normal, api, benda kerja terlempar, atau salah program yang membahayakan, segera lakukan tindakan berikut:

  1. Pukul tombol EMERGENCY STOP (tombol jamur merah) secepat mungkin.
  2. JANGAN membuka pintu pelindung sampai putaran spindle benar-benar berhenti total.
  3. Matikan aliran listrik dan putar Main Switch ke posisi OFF jika memungkinkan.
  4. Segera laporkan kejadian kepada Dosen Pengampu atau Laboran yang bertugas. Jangan berusaha memperbaiki kerusakan sendiri!
